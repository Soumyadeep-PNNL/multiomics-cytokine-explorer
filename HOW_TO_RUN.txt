============================================================
 Multiomics Cytokine Explorer v4 — How to Run
============================================================

REQUIREMENTS
  - R 4.2 or later  (https://cran.r-project.org)
  - RStudio          (https://posit.co/download/rstudio-desktop/)

------------------------------------------------------------
 FIRST-TIME SETUP
------------------------------------------------------------

STEP 1 — Install R packages (once)
  In RStudio console:
    source("install_packages.R")

STEP 2 — *** DELETE THE OLD CACHE (IMPORTANT) ***
  If you see a file named  data_cache.rds  in the App folder,
  delete it manually before the first run.
  (It was built by an old parser and will give wrong results.)

  In the App folder, delete:
    data_cache.rds   (47 MB, dated before May 24 2025)

STEP 3 — Run the app
  Option A: Open app.R in RStudio → click "Run App"
  Option B: In the R console:
    setwd("path/to/App/")
    shiny::runApp("app.R")

  First run will parse all 25 .xlsx files (~60-90 sec).
  It automatically saves a fresh data_cache.rds when done,
  so all subsequent launches take ~2 seconds.

------------------------------------------------------------
 GITHUB — Version control
------------------------------------------------------------
The source files (app.R, data_loader.R) are tracked in git.
To push to GitHub:

  1. Create a repo at https://github.com/new
     Name it: multiomics-cytokine-explorer

  2. In your terminal, from the "Need to make a app" folder:
       git remote add origin https://github.com/YOUR_USERNAME/multiomics-cytokine-explorer.git
       git branch -M main
       git push -u origin main

  3. After any future changes:
       git add app.R data_loader.R
       git commit -m "describe your change"
       git push

------------------------------------------------------------
 APP TABS
------------------------------------------------------------

TAB 1 — Overview
  Metadata table for all 25 packages.
  Filter by model, treatment, omics type.

TAB 2 — Bulk Omics (RNA-seq, Proteomics, ATAC-seq, etc.)
  - Cascading filters: Model → Treatment → Package → Layer → Comparison
  - Significance sliders: p-value, adj p-value, |log2FC|
  - Volcano plot (interactive, top genes labeled)
  - MA plot
  - Heatmap (top significant genes)
  - Downloadable data table
  NOTE: Packages with replicate-averaged data (Pck011,018,019,020,021)
  are flagged as "replicate_averaged=TRUE" in the table.

TAB 3 — scRNA / snRNA
  - Packages: Pck004, 009, 022, 023, 024
  - Filter by cell type and treatment/comparison
  - Same plots as Bulk Omics
  - Pck022: ln(FC) was auto-converted to log2FC on load

TAB 4 — Gene Search  *** NEW ***
  - Type any gene or protein names (comma- or line-separated)
  - Example: STAT1, IRF1, MX1, IFIT1, IFIT2
  - Dot plot: gene × dataset, color = log2FC, size = -log10(p)
  - Bar chart: per-package log2FC for each gene
  - Summary table with all matching rows, downloadable

TAB 5 — Multi-Dataset
  - Select 2+ packages with the same omics type
  - Heatmap of top variable genes across datasets
  - Summary table

------------------------------------------------------------
 DATA NOTES
------------------------------------------------------------
Excluded packages (not shown in plots):
  Pck012, 017 — alternative splicing (ΔPSI data, not fold change)
  Pck014      — phospho-intensity matrix (no gene identifiers in rows)
  Pck015      — top-down proteomics catalog (no differential stats)

  Pck011, 018, 019, 020, 021

scRNA-seq packages:
  Pck004 (6 patient sheets), 009, 022 (ln→log2 converted), 023, 024
